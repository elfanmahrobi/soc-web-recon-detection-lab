# MITRE ATT&CK Mapping

## Primary Mapping

- **Tactic:** Reconnaissance (`TA0043`)
- **Technique:** Active Scanning (`T1595`)
- **Sub-technique:** Vulnerability Scanning (`T1595.002`) when a vulnerability scanner is used in the controlled scenario

## Mapping Rationale

The simulated source actively sends requests to a web service to identify exposed content, accessible paths, service characteristics, or potential weaknesses. The Apache logs provide observable evidence of this activity.

## Limitation

A MITRE ATT&CK mapping describes behavior, not intent. Similar patterns can be generated by legitimate monitoring systems, search engines, approved scanners, or developers. Analyst validation is required before classifying the event as malicious.
